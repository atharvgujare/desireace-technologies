## 1. Free Company Website Hosting (Worldwide Access & Free SSL)

Your agency marketing website is fully coded and ready at:
`d:\StartUp-v1\agency-website` (contains `index.html` and `assets/`).

### Method A: Netlify Drop (Easiest — 30 Seconds, No CLI)
1. Open [app.netlify.com/drop](https://app.netlify.com/drop) in your browser (create a free account if not logged in).
2. Open Windows File Explorer and navigate to `d:\StartUp-v1`.
3. Drag and drop the **`agency-website`** folder directly into the Netlify Drop box.
4. Netlify will deploy it instantly to a live worldwide URL (e.g. `https://desireace-agency.netlify.app`).
5. In Netlify Site Settings &rarr; Change site name &rarr; change it to `desireace-technologies` (gives you `https://desireace-technologies.netlify.app`).

### Method B: GitHub Pages (Free Forever)
1. Create a free repository on [github.com](https://github.com) named `desireace-agency` or `desireace-technologies`.
2. Push your `agency-website` files to GitHub:
   ```bash
   cd d:\StartUp-v1\agency-website
   git init
   git add .
   git commit -m "Launch DesireAce Technologies Agency Website"
   git remote add origin https://github.com/<YOUR_USERNAME>/desireace-agency.git
   git push -u origin main
   ```
3. In GitHub &rarr; Repo **Settings** &rarr; **Pages** &rarr; select `main` branch &rarr; Save.
4. Your site will be live at: `https://<YOUR_USERNAME>.github.io/desireace-agency/`.

1. Sign up on [zoho.com/mail/zohomail-pricing.html](https://www.zoho.com/mail/zohomail-pricing.html) and select the **Forever Free Plan** (scroll to bottom).

## 4. Free Contact Form Notifications (Web3Forms)

Your website contact form is wired to send form submissions straight to your inbox without running any email server:
1. Go to [web3forms.com](https://web3forms.com) (100% free tier: 250 submissions/month).
2. Enter your email (`desireacetech@gmail.com`).
3. Copy your free Access Key.
4. In `d:\StartUp-v1\agency-website\index.html` (around line 799):
   Replace `YOUR_ACCESS_KEY_HERE` with your access key.
5. Whenever a visitor in the US or Europe fills out the form on your website, you receive an instant email notification!
